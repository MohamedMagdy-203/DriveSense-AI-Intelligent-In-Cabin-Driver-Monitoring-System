# MediaPipe Face Landmarker Benchmark Results

This file is generated by
[`face_landmarker_benchmark.py`](face_landmarker_benchmark.py). It will contain
the CPU/GPU measurements after the benchmark is run with a webcam.

Run from the repository root:

```powershell
python -m pip install -r requirements.txt
python experiments\face_landmarker\face_landmarker_benchmark.py `
  --model models\face_landmarker.task `
  --delegate both `
  --duration 60 `
  --trials 3
```

Press `q` to stop a trial early. GPU delegate initialization can fail on
platforms where MediaPipe Tasks GPU is unavailable; in that case run
`--delegate cpu` and record the GPU limitation separately.
